# Archived runs

Superseded artifacts, kept for provenance. Nothing here should be pooled with
new runs. Read any generations file with:

    python analyze.py --file runs/archive/<file>

## Why these are superseded

The problem sampler changed after these runs: `config.problem_ids` is now a
seeded shuffle-prefix (samples nest by construction across n and across
datasets), where these runs drew ids with `random.sample`. The two samplers
return DIFFERENT problem ids, so accuracy here is not problem-for-problem
comparable with anything generated by the current code. Filenames also predate
the current `runs/{dataset}_n{n}_{band}.jsonl` convention.

## Contents

| file | what it is |
|---|---|
| `gsm8k_baseline.jsonl` + `gsm8k_scores.jsonl` + `gsm8k_manifest.json` | the n=20 no-ablation baseline (direct 45%, cot 90%, nothink 90%). The manifest pins the direct-condition prompt whose fingerprint `probes/capture.py` asserts. |
| `m8_gsm8k_n150_light.jsonl` + `_pin.json` | the n=150 direct-arm run, light band: intact 26.0%, ablated 24.7%, random 28.0% — the selectivity null (+3.3 pts, 95% CI [-2.7, +9.3]). The pin records model revision, dataset fingerprint, and problem ids. |
| `m8_gsm8k_n1_light_pin.json` | pin from an `--n 1` timing probe; no data file, kept because it records per-cell seconds. |
| `m7_calibration_light.txt`, `m7_damage_floor_light.txt` | console output of the calibration and damage-floor probe runs the config decisions cite. |
| `smoke*.jsonl/json` | throwaway pipeline smoke-test output from early development. No scientific content. |
